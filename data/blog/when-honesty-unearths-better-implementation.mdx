one time, we were talking about how to correctly name a function, the function in question checks the value and mutates it to null if certain conditions are met, like a reset

now the intent of this function is to make sure a value getting retrieved is always up to date, it was initially named as `get`, and ofcourse this has "that smell", a `get` that mutates, something doesn't feel right.

so we continued the converstation, and pointing that naming this function `get` is a little "dishonest", as it has some mutations, after some more back and forth, we settled with an implementation where the mutation was removed, and we concluded that setting it to null is not necessary and we just need to update some condition where we plan on using that function.
